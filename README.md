# (OAC)
OAC全称 Old Ai Chat 是针对老安卓开发的ai对话app。
目前测试了一台安卓2.3机器，安卓4.22学习机，安卓16手机都能正常运行。
本app其实只是搭建了个平台，能不能用还是得看手机能不能和服务器握手，吃不吃HTTPS。
但安卓2.3手机大部分应该也都能吃HTTPS了吧？反正app目前最低兼容安卓2.3，大家可以自行测试。

若失败了，这不是你的问题，然而我们也没有错，你可以尝试搭建代理平台。

我推荐用自己的API，因为公共api经常被盗刷导致崩掉（）
